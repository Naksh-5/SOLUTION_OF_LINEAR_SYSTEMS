Theory of Solution of Linear Systems by Matrix Method

Introduction

A system of linear equations can be represented in matrix form as AX = B, where A is the coefficient matrix, X is the vector of unknowns, and B is the constant vector. The solution to this system depends on the properties of matrix A.

Matrix Representation

Given a system of n linear equations with n unknowns:

a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ = b₁

a₂₁x₁ + a₂₂x₂ + ... + a₂ₙxₙ = b₂

...

aₙ₁x₁ + aₙ₂x₂ + ... + aₙₙxₙ = bₙ

In matrix form: AX = B

where:

A = [[a₁₁, a₁₂, ..., a₁ₙ], [a₂₁, a₂₂, ..., a₂ₙ], ..., [aₙ₁, aₙ₂, ..., aₙₙ]]

X = [x₁, x₂, ..., xₙ]ᵀ

B = [b₁, b₂, ..., bₙ]ᵀ

Nature of Solutions

The solution of a linear system depends on the rank of the coefficient matrix A and the augmented matrix [A|B]:

Unique Solution

Occurs when rank(A) = rank([A|B]) = n (number of variables). The system is consistent and has exactly one solution.

Condition: det(A) ≠ 0

Infinite Solutions

Occurs when rank(A) = rank([A|B]) < n. The system is consistent but has infinitely many solutions.

Condition: det(A) = 0, but system is consistent

No Solution

Occurs when rank(A) < rank([A|B]). The system is inconsistent and has no solution.

Condition: det(A) = 0 and system is inconsistent

Solution Methods

  1. Matrix Inversion: X = A⁻¹B (only when A is invertible)
  2. Gaussian Elimination: Transform to row-echelon form and back substitute
  3. LU Decomposition: Factor A into lower and upper triangular matrices
  4. Cramer's Rule: Use determinants (for small systems)
  5. Gauss-Jordan Elimination: Transform to reduced row-echelon form

Applications in Information Technology

Solution of linear systems is used in:

  • Computer Graphics: 3D transformations and perspective projections
  • Network Analysis: Solving for traffic flow in computer networks
  • Machine Learning: Solving normal equations in linear regression
  • Cryptography: Solving systems in coding theory
  • Data Compression: Singular Value Decomposition (SVD)

Matrix Solution Example

Solving AX = B using matrix method:

System:

2x + 3y = 8

4x + y = 6


Matrix form:

[2 3] [x] = [8]

[4 1] [y] [6]


Solution:

X = A⁻¹B = [x] = [1]

[y] [2]


Unique solution exists since det(A) = -10 ≠ 0

Pretest - Types of Solutions with Examples

This section demonstrates the three types of solutions for linear systems with proper examples and visual representations.

Unique Solution Example

System:

2x + y = 5

x - y = 1

Matrix Form:

[2 1] [x] = [5]

[1 -1] [y] [1]

Solution:

x = 2, y = 1

det(A) = -3 ≠ 0, so unique solution exists

Visual Representation:

Two lines intersecting at a single point (2, 1)

Intersection at (2, 1)

Unique solution point

Infinite Solutions Example

System:

2x + 4y = 8

x + 2y = 4

Matrix Form:

[2 4] [x] = [8]

[1 2] [y] [4]

Solution:

y = (4 - x)/2 for any x

Infinite solutions along the line

det(A) = 0, rank(A) = rank([A|B]) = 1 < 2

Visual Representation:

Two coincident lines (same line)

Coincident lines

Infinite points of intersection

No Solution Example

System:

2x + y = 5

2x + y = 7

Matrix Form:

[2 1] [x] = [5]

[2 1] [y] [7]

Solution:

No solution exists

det(A) = 0, rank(A) = 1, rank([A|B]) = 2

System is inconsistent

Visual Representation:

Two parallel lines that never intersect

Parallel lines

No intersection point

Key Takeaways

1. Unique Solution: Lines intersect at exactly one point (det ≠ 0)

2. Infinite Solutions: Lines are coincident (same line) (det = 0, consistent)

3. No Solution: Lines are parallel (det = 0, inconsistent)

Posttest - Evaluate Your Learning

Complete this posttest to evaluate your understanding of linear system solutions after going through the experiment. After submitting, explanations will be shown for each question.

Question 1: When does a linear system have a unique solution?




Explanation: A linear system has a unique solution when the determinant of the coefficient matrix A is non-zero (det(A) ≠ 0). This means the matrix is invertible and the system is consistent and independent.

Question 2: What does it mean when rank(A) = rank([A|B]) < n?




Explanation: When rank(A) = rank([A|B]) < n (where n is the number of variables), it means the system is consistent but has dependent equations. This results in infinite solutions, with (n - rank) free variables.

Question 3: In the matrix method, how is the solution represented?




Explanation: The solution is represented as X = A⁻¹B, where A⁻¹ is the inverse of the coefficient matrix. This method can only be used when A is invertible (det(A) ≠ 0).

Question 4: Which method is most efficient for solving large systems of linear equations?




Explanation: Gaussian Elimination is generally the most efficient for large systems with O(n³) operations. Cramer's Rule requires calculating n+1 determinants, which is O(n!) operations, making it impractical for large systems.

Question 5: What does it mean if a system has "infinite solutions"?




Explanation: Infinite solutions means there are multiple (infinitely many) sets of values that satisfy all equations simultaneously. This occurs when the equations are not independent (one or more equations can be expressed as combinations of others).

Question 6: In the context of linear systems, what does "consistent" mean?




Explanation: A system is consistent if it has at least one solution (either unique or infinite). An inconsistent system has no solution. Consistency is determined by comparing the rank of A with the rank of the augmented matrix [A|B].
