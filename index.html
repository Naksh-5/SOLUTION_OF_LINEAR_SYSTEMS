Solution of Linear Systems

AIM: To find the solution of linear systems

This experiment aims to provide a comprehensive understanding of methods for finding solutions to systems of linear equations, which is a fundamental technique in numerical methods.

Understanding different types of solutions (unique, infinite, or no solution) is crucial for algorithm design and system analysis in various applications.

Theory of Linear Systems

Introduction to Linear Systems

A system of linear equations is a collection of one or more linear equations involving the same set of variables. The general form of a system of m linear equations in n variables is:

a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ = b₁
a₂₁x₁ + a₂₂x₂ + ... + a₂ₙxₙ = b₂
...
aₘ₁x₁ + aₘ₂x₂ + ... + aₘₙxₙ = bₘ

Where:

  • x₁, x₂, ..., xₙ are the variables
  • aᵢⱼ are the coefficients (i = 1,...,m; j = 1,...,n)
  • bᵢ are the constants (i = 1,...,m)

Types of Solutions

A system of linear equations can have one of three types of solutions:

1. Unique Solution

The system has exactly one solution. The equations represent intersecting lines/planes at a single point.

Example: 2x + y = 5, x - y = 1

Solution: x = 2, y = 1

2. Infinite Solutions

The system has infinitely many solutions. Equations are dependent and represent the same line/plane.

Example: x + 2y = 4, 2x + 4y = 8

Solution: All points on the line x + 2y = 4

3. No Solution

The system has no solution. Equations are inconsistent and represent parallel lines/planes.

Example: x + y = 3, x + y = 5

No solution exists

Solution Methods

1. Gaussian Elimination

This method involves three types of row operations:

  • Swapping two rows
  • Multiplying a row by a non-zero scalar
  • Adding a multiple of one row to another row

2. Gauss-Jordan Elimination

An extension of Gaussian elimination that produces reduced row echelon form.

3. Matrix Inversion Method

If A is invertible, the solution is given by X = A⁻¹B

4. LU Decomposition

Decompose matrix A into lower (L) and upper (U) triangular matrices, then solve.

Matrix Properties and Solution Existence

Determinant: A scalar value that determines if a matrix is invertible.

det(A) ≠ 0 ⇒ Unique Solution

Rank: The maximum number of linearly independent rows/columns.

rank(A) = rank([A|B]) ⇒ Consistent System

Conditions for Solution Existence:

  1. If rank(A) = rank([A|B]) = n (number of variables): Unique Solution
  2. If rank(A) = rank([A|B]) < n: Infinite Solutions
  3. If rank(A) ≠ rank([A|B]): No Solution

Graphical Interpretation

In 2D (Two Variables):

  • Two lines intersect at a point: Unique Solution
  • Two lines are coincident: Infinite Solutions
  • Two lines are parallel: No Solution

In 3D (Three Variables):

  • Three planes intersect at a point: Unique Solution
  • Three planes intersect along a line: Infinite Solutions
  • Planes don't all intersect: No Solution

Posttest - Practical Problem Solving

Problem 1: Solve the following system using Gaussian Elimination:
2x + 3y = 8
4x - y = 6
Problem 2: Determine the nature of solution for:
x + 2y = 4
2x + 4y = 8
Problem 3: Solve the 3×3 system:
2x + y - z = 8
-3x - y + 2z = -11
-2x + y + 2z = -3
Problem 4: Calculate the determinant of matrix A for the system and determine solution type:
A = [[1, 2], [2, 4]]
Problem 5: A system has rank(A) = 2 and rank([A|B]) = 3 with 3 variables. What type of solution exists?

Solutions to Posttest Problems

Problem 1 Solution:

Using Gaussian Elimination:

Step 1: [2 3 | 8]
       [4 -1 | 6]
Step 2: R2 → R2 - 2R1
       [2 3 | 8]
       [0 -7 | -10]
Step 3: y = 10/7 ≈ 1.43
Step 4: 2x + 3(10/7) = 8
       2x = 8 - 30/7 = 26/7
       x = 13/7 ≈ 1.86

Correct Answer: None of the given options exactly match, but closest is x = 2, y = 1

Problem 2 Solution:

The second equation is exactly twice the first equation:

2(x + 2y) = 2(4) ⇒ 2x + 4y = 8

This means both equations represent the same line. Therefore, the system has infinite solutions.

Problem 3 Solution:

Solving using Gaussian Elimination:

Step 1: Write augmented matrix
       [2 1 -1 | 8]
       [-3 -1 2 | -11]
       [-2 1 2 | -3]
Step 2: After elimination
       x = 2, y = 3, z = -1

Correct Answer: x = 2, y = 3, z = -1

Problem 4 Solution:

Calculate determinant:

det([[1, 2], [2, 4]]) = (1×4) - (2×2) = 4 - 4 = 0

When determinant is zero, the system has either no solution or infinite solutions. For this specific matrix, since the second row is twice the first row, the system has infinite solutions.

Problem 5 Solution:

According to the rank theorem:

  • If rank(A) = rank([A|B]) = n → Unique Solution
  • If rank(A) = rank([A|B]) < n → Infinite Solutions
  • If rank(A) ≠ rank([A|B]) → No Solution

Here, rank(A) = 2 ≠ rank([A|B]) = 3

Therefore, the system has no solution.
